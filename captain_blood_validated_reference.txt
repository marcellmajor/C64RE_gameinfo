CAPTAIN BLOOD (COMMODORE 64)
VALIDATED MEMORY, ROUTINES, CONVERSATION AND QUEST REFERENCE
Prepared 2026-09-27

1. SCOPE AND HOW TO READ THIS REFERENCE
======================================

This reference consolidates the local reverse-engineering notes with the
corrections in validation_report.md. It describes the program image in
memdump_dir/landed_blood.bin and the alien conversation script loaded in that
image. It is not a complete reconstruction of every quest in the game.

Evidence labels:
  [CODE]   Supported by saved machine code or data.
  [EXEC]   Also exercised using the saved code in an isolated 6502 emulator.
  [INFER] Gameplay meaning inferred from code; exact UI action unconfirmed.
  [STORY] Interpretation of what the alien dialogue says.
  [OPEN]  Not established by the available evidence.

Unless otherwise marked, the technical tables describe [CODE] findings.
The characters are called "aliens" here: some are friendly or ask for help,
while others threaten Blood. They are not uniformly enemies.

All $-prefixed addresses and values are hexadecimal. Unprefixed planet indices,
word IDs, flag numbers, dimensions and coordinates are decimal. Planet indices
are zero-based: planet 0 is the first entry in the game's 64-entry tables.
An internal planet index is not necessarily its spoken name or number.

The saved image has the ship on planet 0 at (145,69), with alien file 0 loaded.
File 0 serves planet/alien indices 0-3. Coordinates shown later are specific to
this saved game; new-game code generates the coordinate tables again.

Validation basis:
  - 65,536-byte RAM image.
  - Decoder output reproduced exactly.
  - 256 script records: 187 patterns, 39 actions, 30 conditions.
  - 1,247 matcher probes across all 187 patterns passed.
  - Both password mechanisms and all four coordinate replies were exercised.
  - A read-only VICE check of $4C00-$4DFF matched the saved image exactly.

The CPU probes used a private memory copy. They bypassed SID entropy collection
and player-row graphics and did not emulate interrupts or the full user
interface. They confirm interpreter behavior under the specified state, not a
complete unmodified VICE playthrough.

2.1 CPU/VIC configuration in the saved conversation screen

                $A000-$BFFF and $E000-$FFFF are RAM in this configuration.
  $DD00 = $94   Selects VIC bank at $C000.

  $FFFA/$FFFB -> $1206, an RTI instruction.
  $FFFC/$FFFD -> $1206.

These are stored vector values; RESET is not equivalent to a normal interrupt
return, and this is not a claim that a hardware reset can safely be ignored.

2.4 Game flags

Flag address and mask:
  address = $9210 + floor(n / 8)
  mask    = 1 << (n mod 8)

F1-F4       Which member of the four-planet alien file is being encountered.
             For planet index i, the game sets F((i AND 3) + 1).
F5          Read by the alien-transport routine and saved in $EB.
F6          Conversation-script request enabling an additional UI action.
             The loop tests it before updating the menu. The transport meaning
             follows the surrounding code; the exact player UI is [INFER].
F7          Encounter state with a nominal 1/16 random set opportunity per
             $4991 start, and a countdown fallback. Initially $FB=15; without
             an earlier random hit, start 16 forces F7. Automatic greeting
             initialization also calls this routine. Continuation clicks do
             not run the fresh-start random/countdown logic.
F8          Set at encounter initialization if the home lead is marked visited.
F9          Refreshed with a nominal 1/4 random set opportunity per fresh start.
F10-F29     Temporary conversation state. Reset on a new encounter.
F40-F49     Set by new-game initialization.

F100 + 5*i + k is per-planet state for index i and slot k=0..4:
  k=0,3    Set by $479F; cleared by $47E5.
  k=0,1    Cleared by relevant departure bookkeeping at $4D57.
  k=2      Home-position match state recomputed by landing classification.
  k=4      Used for the recognized alien's $DC status.

The home-position flag is commonly described as "alien at home". The actual
classifier also checks visited/location state; it is not a general-purpose
comparison of the two coordinate arrays independent of landing logic.

Persistent flags used by file 0 include:
  F100     Planet-0 slot 0; part of the planet-1 story gate.
  F102     Planet-0 home-position flag.
  F103     Planet-0 slot 3; cleared by the away-from-home Yoko sequence.
  F108     Planet-1 slot 3; set by that sequence.
  F118     Planet-3 slot 3; set by that sequence and cleared at the final reveal.
  F420     Small Yoko's completed greeting/introduction memory.
  F435     Maxon's successful first story stage completed.
  F436     Maxon's later accusation stage completed.
  F437     Excludes Maxon's final block when set. File 0 does not set it.
  F999     False barrier in this script; new-game code clears it and file 0
             does not set it. Other alien files have not been audited.

4. HOW THE CONVERSATION SYSTEM WORKS
====================================

4.1 Player interaction

Select pictogram words from the vocabulary grid. The player composition is on
the RIGHT; the alien's reply appears on the LEFT. The player buffer has eight
icon slots. Clicking inside the player row moves the insertion cursor; the
existing words after that position are not simply discarded.

The mouth control invokes interpretation. In screen coordinates, its hotspot
is x=144..175, y=107..126. These are bitmap-screen coordinates, excluding the
emulator window's border and scaling. The rectangle table itself stores X/2.

Conversation hotspot summary (upper bounds exclusive):
  Region   Screen X       Screen Y       Purpose
    0      [24,56)        [180,200)       Lower-left control
    1      [264,296)      [180,200)       Lower-right control
    2      [64,256)       [183,207)       Bottom scroll strip
    3      [48,272)       [137,175)       Two-row vocabulary grid
    4      [176,304)      [112,134)       Player message row
    5      [16,144)       [112,130)       Alien reply row
    6      [272,300)      [136,156)       Upper right-side control
    7      [272,300)      [156,176)       Lower right-side control
    8      [144,176)      [107,127)       Mouth / speak

The blinking graphic occupies 32 x 32 pixels at (144,104), overlapping the
mouth area. Its countdown is eight main-loop iterations, approximately 48
frame-counter ticks while idle, with additional delays possible.

4.2 Fresh input versus continuation

Fresh input ($E5=0):
  1. Convert all eight $5C80 slots through $9718 into $5CA0.
  2. Terminate the word list with $FF and clear/redraw the player row.
  3. Reject an empty converted player message.
  4. Reset the script walk to its beginning and update fresh-start flags.
  5. Walk conditions and patterns until a reply is produced or the walk stops.
  6. Convert the reply at $5CB0 to icons at $5C90 and animate it.

Continuation ($E5 nonzero):
  - The next mouth click resumes the walk with the SAME earlier player words.
  - A newly composed message is not read by that continuation click.
  - Consecutive action records may already have run after a matched pattern.
  - Continue clicking to receive later eligible replies in script order.
  - When no further reply is produced, continuation clears. New player input
    can then be accepted. An encounter-ending action instead sets $E7 and
    disables further normal conversation for that encounter.

This is why a useful answer is often several mouth clicks after the phrase
that triggered it. It is also why entering the answer to a question too early
may appear ineffective: the game may still be continuing the previous input.

The automatic greeting uses $4934 rather than an ordinary fresh player
message. Its continuations can emit unconditional lines even with no player
words in the internal list.

4.3 Record format and matching

Script address = $6100 + little-endian word at $6100/$6101.

Each ordinary record contains:
  byte 0: type in bits 7-5, operand BYTE count in bits 4-0
  byte 1: type-specific flags
  following bytes: operands
The single byte $FF marks the script end.

Identified types:
  $00 PATTERN  Tests player words and supplies alien reply words.
  $40 ACTION   Sets/clears game flags; zero operands ends the encounter.
  $80 CONDITION Tests game flags and controls which following block is visited.
  $A0 TIME     Passes when elapsed minutes are greater than its threshold.
  $C0 TIME     Passes when elapsed minutes are at most its threshold.
Only $00/$40/$80 occur in file 0. Other type values are not characterized here.

Pattern flags:
  $80 used       Already matched in this encounter.
  $01 repeat     Allows matching again despite used status.
  $08 random     Skips the record when (RNG AND 7) equals 7.
  $04 ordered    Requires operands as an ordered subsequence of player words.
                  No file-0 pattern uses this mode.
  $02 always     Bypasses ordinary word-content tests in the unordered path.

Pattern operands have three packed metadata bits each:
  Plane 0 set:    REQ  - this word must occur in the player message.
  Plane 1 clear:  SAY  - include this operand in the alien reply.
  Plane 2 clear:  TRIG - optional word can contribute a positive match.

For the ordinary unordered mode, all REQ words must occur, and at least one
REQ or eligible TRIG word must be found. Extra words are permitted. Order
does not matter for the file-0 passwords. A trigger need not be spoken back;
a spoken word need not be a trigger.

A matched pattern with no SAY operands is silent. The engine can execute its
following actions and keep scanning until it finds an audible reply. A
pattern skipped because its words did not match does not automatically cause
its following action records to execute.

Bit-plane address for logical pattern-operand index j and plane p=0,1,2:
  address = $6108 + 3*floor(j/8) + p
  mask    = $80 >> (j mod 8)

The index counts logical operands, not records or raw bytes. A special token
with two parameter bytes still occupies one logical operand position.

Condition/action flags have different meanings from pattern flags. Condition
bit $80 is a stop-on-failure barrier, not an already-used marker. Bits $40/$20
participate in block boundaries/skipping; file-0 major blocks use flags $60.
Action bit $01 implements once-only behavior through its used bit, not the
pattern's repeat behavior. File-0 action flags are all zero.

Flag operands are signed two-byte values: positive n tests/sets Fn; a negative
encoding represents !Fn for a test, or clearing Fn for an action. Conditions
combine their listed flag requirements before admitting their block.

4.4 Reply tokens and coordinates

Most reply bytes are vocabulary word IDs, mapped to icon indices through
$5C00. The special three-byte tokens are:
  [1,a,b] HOUR       Formats a value; zero parameters use the current clock.
  [2,a,b] FREQUENCY  Consumes both parameters but this reply routine does not
                     append numeric digit icons for them.
  [3,a,b] COORDINATE Selects a position and renders X, a separator, then Y.

For a COORDINATE token:
  if a != 0:
      i = a - 1
      X = memory[$0600 + i]
      Y = memory[$0640 + i] AND $7F
  otherwise:
      i = b - 1
      X = memory[$0680 + i]
      Y = memory[$06C0 + i] AND $7F

The token starts with the coordinate pictogram and appends decimal digit icons
with separator icon $6F. Sending the COORDINATE pictogram is not a universal
request for coordinates: player conversion drops word ID 3. The reliable
method is to satisfy the particular alien's story and password conditions.

4.5 Practical conversation habits

  - Start with a relevant short phrase; up to eight icons fit.
  - Keep clicking the mouth through pending replies before sending a new answer.
  - Listen past general chatter to reach the character's own script block.
  - Do not assume an early friendly reply means the requested quest action ran.
  - Separate temporary encounter flags from persistent story progress.
  - Some lines are random-gated; an omitted line does not necessarily mean
    the required word or password was wrong.

Examples of words that avoid the general file-0 chatter triggers are BLOOD,
ME, YOU, YES, NO, PLANET, IDEA, CODE, POP and MAXON. "Avoid general chatter"
does not mean "safe answer to every question": NO can fail an identity test,
and PLANET can trigger Yoko's own quest logic once introduced.

YOKO, RENDEZ-VOUS, DEAD, KNOW, FRIEND and several other quest words also match
earlier general chatter. That usually costs extra continuation clicks.
Hostile vocabulary can end an encounter: the general CURSE reply, when it
passes its random gate, is followed by an end action; Yoko also has specific
INSULT and KILL+YOKO termination paths.


5. QUESTS AND STORY REPRESENTED BY ALIEN FILE 0
===============================================

The script dispatches by the encounter flag:
  Planet index 0 -> F1
  Planet index 1 -> F2
  Planet index 2 -> F3
  Planet index 3 -> F4
The loader selects alien file floor(i/4), so these four entries share file 0.
After relocation, these indices still identify the same game entries; an

6. HOW TO MAKE ALIENS REVEAL THE NEXT COORDINATES
================================================

There is no single universal "tell me coordinates" phrase. Coordinate replies
belong to specific story blocks. Progress depends on the alien index, persistent
story flags, temporary answers and continuation through the reply sequence.

6.1 Quick reference

  Speaker/state         Player action                  Destination record
  --------------------  -----------------------------  -------------------
  Small Yoko at home    Introduce yourself with BLOOD; No coordinates here.
                        then PLANET, CROOLIS-ULV,
                        ME SEARCH POP, or DEAD GENETIC.
                        Continue to the transport hint.

  Small Yoko away       Enter the F1 + !F102 story     $650E -> home 12.
  from home             state and continue his lines.
                        No additional password.

  Planet-1 claimant    With F2 + F100 + !F103, say    $65DA -> home 60.
                        RENDEZ-VOUS 6 7; continue.

  Maxon final stage    With F4 + !F103 + F436 +       $676B -> home 1;
                        !F437, say YOKO NOT DEAD       $6777 -> home 61.
                        IDEA 3 4 9; continue.

These are script prerequisites and tested conversation outcomes. They are
not a claim that every prerequisite can be reached by an already-verified
sequence of transport and navigation button presses.

6.2 Suggested use of the validated dialogue information

1. On the initial Small Yoko encounter, finish the greeting, answer BLOOD when
   fresh input is accepted, and continue through his response. Once introduced,
   use PLANET for a short trigger, or ME SEARCH POP / DEAD GENETIC for more
   explicit phrases. Continue to the request to teleport him to a good planet.

2. [INFER] Use the game's transport mechanics to move Small Yoko away from his
   home. The associated code is $47C1 for taking aboard and $479F for putting
   down. The exact UI sequence has not been established here. The required
   conversation state is the same alien index 0 with its home flag F102 clear.

3. In the away-state conversation, keep clicking the mouth through the entire
   sequence. Record the coordinates after YOU GO URGENT PLANET TRAP 4. They
   refer to HOME INDEX 12, not internal index 4. Continue through the ending
   so the story's later flag changes have run.

4. At the planet-1 claimant, provided F100 remains set and F103 is clear, use
   RENDEZ-VOUS 6 7. Continue past generic chatter and the claimant's story.
   Record the home coordinates of duplicate index 60. Also note the spoken
   clue IDEA 3 4 9 for Maxon's final stage.

5. At Maxon's introduction stage, answer BLOOD, then YES, then FRIEND, each
   after the previous dialogue has finished accepting continuations. Continue
   to BYE and the stage's ending to establish F435.

6. On a later accessible Maxon encounter, continue through the accusation
   sequence, establishing F436. This sequence provides no coordinates.

7. At Maxon's final stage, send YOKO NOT DEAD IDEA 3 4 9. Keep clicking through
   the general chatter and grief lines. Record BOTH coordinate replies: the
   claimant's home index 1 and duplicate home index 61.

Steps 4 and 5 need not be a rigid chronological order if their flags are
already satisfied and the password is already known. This is a dependency
guide for the dialogue, not a complete navigation itinerary.

6.3 Learning RENDEZ-VOUS 6 7 through the dialogue

If the player does not already know the password, the validated disclosure
in this file is Maxon's identity-failure line. After he asks IDENTITY ?, NO
is a tested failing answer that produces:
  DANGER PLANET RENDEZ-VOUS 6 7 FORBIDDEN

That encounter ends WITHOUT setting F435. A subsequent Maxon encounter still
starts the interrogation stage. Therefore the stage count is:

  Password known beforehand:
    Encounter 1: successful BLOOD / YES / FRIEND introduction -> F435.
    Encounter 2: accusation sequence -> F436.
    Encounter 3: YOKO NOT DEAD IDEA 3 4 9 -> final coordinates.

  Password learned by failing identity:
    Encounter 1: identity failure reveals RENDEZ-VOUS 6 7; no F435.
    Encounter 2: successful introduction -> F435.
    Encounter 3: accusation sequence -> F436.
    Encounter 4: final password -> final coordinates.

These counts assume the game permits the needed later encounters and the
other gates remain satisfied. Physical revisiting has not been demonstrated.

Useful observation points for a future live test:
  $4948  Mouth-click entry; inspect $E5 to distinguish fresh input/continuation.
  $4BFD  Player conversion; inspect all eight $5C80 slots and resulting $5CA0.
  $49C1  Script walker; inspect $D8/$D9 and $D6/$D7.
  $4C32  Reply builder; inspect $5CB0 before conversion and $5C90 afterward.
  $4E57  Absolute flag clear.
  $4E70  Absolute flag set.
  $47C1  Suspected take-aboard operation.
  $479F  Suspected put-down operation.
  $47E5  Suspected remove/destroy operation.

To check a coordinate without following the story, read:
  home(i)    = (memory[$0600+i], memory[$0640+i] AND $7F)
  current(i) = (memory[$0680+i], memory[$06C0+i] AND $7F)
This is a debugging shortcut, not an in-game dialogue solution.

Addresses frequently misidentified in older notes:
  $4C89  PHA inside the coordinate renderer, not an interpreter entry.
  $4D1C  Planet/visited bookkeeping, not message interpretation.
  $4E51 and $4E6A  Flag operations, not pixel plotting.
  $9210  Flag bitset, not a pixel bitmap.
  $A5/$A6  Graphics-template pointer, not a dialogue pointer.
  $1A03  Inside an instruction operand, not a callable response routine.
  $50D9  Byte in a decompression bitmask table, not a reply-selection table.

The older asm_dir/blood_loaded_0803.asm.txt matches only 27 of its 12,858
instructions at the listed addresses in this image. Use the saved dump and
asm_dir/captainblood_conversation.asm for this address space. The latter is
an execution trace and omits untaken paths; fresh disassembly of the dump is
needed for those paths.
